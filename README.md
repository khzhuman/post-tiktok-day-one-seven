A TikTok video of one tiny agent-built game — Starfall Rooftops — filmed at the identical opening moment on day one and again on day seven, after a week of daily updates: same roofs, same start, visibly more going on. The video ends with make.fun's referral end card. This repository's program copies VIDEO.json (the posted video's TikTok address) to the output for the house gate.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
